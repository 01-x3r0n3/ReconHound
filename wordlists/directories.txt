# reconhound/wordlists/directories.txt
#
# General-purpose directory + file wordlist consumed by
# reconhound/endpoint_discovery.py (context.md §10 module 10, §11 folder
# structure). One combined list covers both Module-10 responsibility 1
# (directory enumeration) and responsibility 2 (file enumeration) — this is
# the single "directories.txt" context.md's folder structure defines; no
# extra wordlist file is invented for files.
#
# Convention read by endpoint_discovery.py:
#   - entries ending in "/" are treated as directory candidates (recursion
#     candidates on a non-404 hit)
#   - all other entries are treated as file/leaf candidates
#
# Blank lines and lines starting with "#" are ignored.
